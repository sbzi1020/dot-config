FTP(File Transfer Protocol) is used to transfer files between a client and a server over a network. Both hosts must have FTP installed. 
FTP data is not always encrypted
FTP uses two default TCP ports: 
	Port ==21== for sending commands (control channel)
	Port ==20== for ==transferring== files (data channel) in active mode.

### Walkthrough
1. Configure both devices with the correct IP address and interface. ==Note: Currently, both devices are down, so you have to set the Router to `no shut` to keep it up.== (The green dots between the cables mean they are connected)
	1. Go to the Server's command prompt to make sure they are connected: [ping](<![[Screenshot 2026-06-29 at 12.48.15 PM.png|248]]>)
2.  (Router)Prepare the file: 
	1.  run `Router#copy running-config startup-config` to copy from running-config(RAM)  to  startup-config(NVRAM)
![[Screenshot 2026-06-29 at 12.53.44 PM.png|266]]
3. (Server)Configure FTP.
	1. Add a user with full access
![[Screenshot 2026-06-29 at 12.55.24 PM.png|278]]
4. (Router) Add FTP user to the Cisco router, the command is from Cisco commands. Other devices should download FTP with different settings.
```
Router(config)#ip ftp username 101labs 
Router(config)#ip ftp password hello
```
5. (Router)Copy the file to the FTP server.

6. (Server) Verify the copied file exists on the FTP server
