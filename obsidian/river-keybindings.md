# River Keybindings Cheat Sheet

| Keybinding                      | Action                                                   |
| ------------------------------- | -------------------------------------------------------- |
| `Alt + B`                       | Open browser (Chrome via dbus-run-session)               |
| `Alt + Return`                  | Open terminal (kitty)                                    |
| `Alt + Q`                       | Close focused window                                     |
| `Alt + F`                       | Toggle fullscreen                                        |
| `Alt + Shift + F`               | Toggle floating                                          |
| `Alt + Shift + H`               | Focus next window                                        |
| `Alt + Shift + L`               | Focus previous window                                    |
| `Alt + M`                       | Swap with next window                                    |
| `Alt + Shift + =`               | Grow master area (main-ratio +0.1)                       |
| `Alt + Shift + -`               | Shrink master area (main-ratio -0.1)                     |
| `Alt + Left-click`              | Move window                                              |
| `Alt + Right-click`             | Resize window                                            |
| `Alt + Control + P`             | Screenshot full screen -> ~/Screenshots                  |
| `Alt + Shift + P`               | Screenshot selected area (grim + slurp) -> ~/Screenshots |
| `Alt + .`                       | Focus next monitor                                       |
| `Alt + ,`                       | Focus previous monitor                                   |
| `Alt + Shift + .`               | Move window to next monitor                              |
| `Alt + Shift + ,`               | Move window to previous monitor                          |
| `Alt + [1-9]`                   | Focus tag                                                |
| `Alt + Shift + [1-9]`           | Move focused window to tag                               |
| `Alt + Control + [1-9]`         | Toggle visibility of tag                                 |
| `Alt + Shift + Control + [1-9]` | Toggle tag on focused window                             |
| `Alt + 0`                       | Focus all tags                                           |
| `Alt + Shift + 0`               | Assign focused window to aijjjkkll tags                  |
